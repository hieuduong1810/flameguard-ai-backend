# Phase 3B and official dataset integration — pending decisions

**Status:** Proposed dependency register, 2026-11-12. No Data Team export has been accepted for backend publication. Public NASA PSI output is an engineering rehearsal; the official hackathon dataset expected November 14, 2026 must be assessed on arrival. This document moves Phase 3B compatibility gates out of the Phase 5–7 feature backlog; it does not move Data Team ETL/import ownership to Backend.

Backend may prepare contracts, validators and isolated acceptance tests under a separately approved Phase 3B scope. Data Team owns source acquisition, ETL, scientific normalization/curation, QA and import execution. AI Team owns model/retrieval validation. Any additive migration requires the [schema evolution policy](../decisions/ADR-0003-schema-evolution-and-hackathon-prototype.md) and explicit approval. The existing 21 tables are a baseline, not a guaranteed fit for new data.

## Prototype findings that must survive handoff

- Data Team's current unified output contains `experiments`, `runs`, `measurements`, `timeseries`, `facts`, `scenarios`, `scenario_priors`, `dataset_catalog`, `rankings`, `fuel_properties` and five `ml_*` views. The [existing build report](../../../Nasa-hackathon-dataprocessing/data/unified/BUILD_REPORT.md) reports 19 investigations, 1,687 runs, 6,574 measurements, 882 time samples, 43 facts and 456 ranking rows. These counts are report evidence, not a rerun or acceptance of official data.
- The backend maps numerical `measurements.metric/value/unit` to `measurement.observable/measured_value/unit` but has no categorical `measurement.value_text`, per-measurement flag or source link. `test_condition.value_text` must not silently replace a categorical measurement.
- `timeseries` has `time_s`, channel metric and value; `measurement.raw_asset_ref` is only a raw asset reference. Define access, version and sample-level API separately.
- Data's `facts.source_ref` is not automatically a `source_document_id` plus exact locator. A citation string or local file path is not enough to construct `source_document.source_url`.
- The existing `scenario_match` is scenario → **test run**. Data's ranking output is scenario/pillar → **investigation**. Do not persist it against an arbitrary run.
- The Dataset Report says no prototype dataset directly measures lunar 1/6 g or Mars 3/8 g. E-FIELD does not supply a voltage-to-gravity mapping. Partial-gravity numbers require AI-owned validated model/domain/uncertainty evidence and must be labeled as modeled, if ever published.

## Work sequencing

**Before November 14:** agree on export/identity/unit/source manifests, prepare read-only field mapping and loss report, define quality and categorical representation options, propose (but do not execute) additive migration impact analysis, and write synthetic contract/isolated acceptance tests under a Phase 3B specification.

**On arrival of the official dataset:** inventory and hash raw files; compare actual fields/types/units/identity/provenance with this register; record accepted, rejected and unknown mappings; decide adapter versus migration from evidence. Update Phase 5–7 provider contracts only after the official dataset's applicable scope is known.

**After approval:** Data Team executes its agreed importer; Backend verifies isolated PostgreSQL readback, versioning, provenance and publication gates. Shared-database imports, destructive migration/reset and scientific validation require their own human/owner approval. Do not treat a passing mock or synthetic API test as real-data integration.
