# Phase 5 provider contract

Owner-authorized fixture engineering contract. Data acceptance of real providers remains pending. Backend owns version/scope validation and orchestration. Data owns ranking computation, scientific variable/quality mapping and classifications. AI has no Phase 5 engine deliverable.

Providers receive detached, immutable scope, scenario and evidence records. Server configuration defaults to unavailable and may explicitly compose TEST_ONLY providers for admitted synthetic/unreviewed snapshots. Client payloads carry no provider mode, URL, review override or filesystem path. Five-second deadline, cancellation propagation and no retry apply. Ranking JSON is bounded to 1 MiB, 12 containers of depth, 1,000 entries and bounded DTO fields. Invalid JSON, duplicate keys, unexpected fields and unknown identities reject the delivery before pagination. Provider exceptions and arbitrary payload text never appear in responses. The engineering ranking adapter only permits known fixture explanatory strings.

## Run decisions

A fixture-only provider uses exact equality against explicitly named fixture conditions. Each decision retains references to its run's condition IDs. Backend validates six unique decisions, same-run membership and combined support. Oxidizer oxygen and ambient oxygen stay distinct. Unsupported units, missing values, flagged values and conflicting originals cannot supply support. No scientific tolerance, conversion or operational verdict is approved.

## Ranking delivery

The fixed adapter returns pre-authored investigation ranks/ties, applicability, version metadata and component scores. Backend validates collection, identity, scenario interpretation version, scenario, material, pillar, position, ties, required components and declared fixture scales before any page is accepted. No weight, score or fallback computation. Raw export reference/checksum and real ranking activation await D-04.

## Classification

Explicit versioned claim-to-pillar mapping plus admitted claim-source associations establish fixture classification. The classification describes the admitted collection and requested pillar scope. Matching source/document/locator identities and original run context are preserved. Empty groups carry scoped reasons. Sources and claims retain their independent stored statuses and synthetic labels. Replay binds the validated association-to-pillar mapping. Real mapping and source review await D-05.
