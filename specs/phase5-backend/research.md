# Phase 5 design decisions

- Use the owner-selected POST from the Phase 5 backlog and keep the Phase 4 router intact. F-01 still requires consumer evidence.
- Bind replay to admitted content and slug mapping, scenario lexical digest and provider versions. Use a complete ranking delivery binding for ranking continuation.
- Restrict fixture comparisons to explicit matching labels/values, keep separate oxygen meanings and preserve unit originals. Treat policy and scientific publication as external.
- Use fixed ranking records through a bounded adapter. Data's ranking implementation remains upstream.
- Page explicit classification associations by association UUID, retaining claim, source and optional run context.
- Persist a lossless complete scenario subset through a trusted service. The evaluation read path remains stateless.
